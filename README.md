
## Project Summary

This Digital Literacy Project is developed as part of **CSE0001 – Digital Literacy** course at VIT Bhopal University. The main purpose of this project is to improve digital awareness and help students understand how to use digital platforms in a safe and professional way. As part of this project, I completed five different tasks related to digital literacy and online communication.

In Task 1, I created a Digital Literacy Awareness infographic using an online design tool. This infographic explains the meaning of digital literacy, safe internet practices and useful digital tools for students. This task helped me understand how important digital awareness is in today’s academic environment.

In Task 2, I built my student digital portfolio by creating and updating profiles on platforms like GitHub, LinkedIn and other professional websites. This task helped me understand how to create a professional online presence and maintain digital identity.

In Task 3, I explored coding and collaboration platforms. I completed a beginner level coding challenge and also created a Google Form quiz related to digital literacy. This task helped me learn about online collaboration and coding practice platforms.

In Task 4, I drafted professional emails and created a social media Do's and Don'ts checklist. This task improved my professional communication skills and helped me understand email etiquette.

In Task 5, I created a cybercrime awareness case study and prevention checklist. This helped me understand different types of cyber threats and how to stay safe online.

Overall, this project helped me improve my digital literacy, communication skills and awareness about safe and responsible internet usage.
